# Capas dos 50 filmes novos

O catálogo já está pronto em `src/dados/catalogo.js`. Falta só colocar as imagens das capas.

## Como colocar
1. Procure o cartaz oficial de cada filme (busque "título + ano + poster" ou use o site oficial do filme).
2. Salve a imagem na pasta `public/img/` **com exatamente o nome da coluna "Arquivo"**, em `.jpeg` (se vier `.jpg` ou `.png`, renomeie ou converta para `.jpeg`).
3. Tamanho bom: cerca de 500 × 750 pixels (proporção de cartaz, em pé).
4. Recarregue o site. Enquanto uma capa não existir, o card mostra um bloco verde com o título, então nada quebra.

As capas pertencem aos detentores dos direitos. Para trabalho escolar sem fins comerciais é uso comum, mas não publique o site como se fosse um serviço de streaming.
